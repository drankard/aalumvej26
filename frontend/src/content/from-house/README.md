# Fra Ålumvej 26 — first-hand notes

One file per place, per language. The whole file is the note — there is no
syntax to get wrong, so nothing you type here can break the site.

## Adding one

**File name:** `<slug>.<lang>.md`

The slug is the last part of the page's address. For

    https://www.aalumvej26.dk/oplevelser/lodbjerg-fyr-klatr-op-i-fyret-og-drik-kaffe-i-den-gamle-fyrm/

the slug is `lodbjerg-fyr-klatr-op-i-fyret-og-drik-kaffe-i-den-gamle-fyrm`, so the
Danish note goes in

    lodbjerg-fyr-klatr-op-i-fyret-og-drik-kaffe-i-den-gamle-fyrm.da.md

Languages are `da`, `en`, `de`. Danish alone is fine — a language with no file
simply shows nothing there, which is better than showing a German reader Danish.

On github.com: open this folder, **Add file → Create new file**, paste the name,
type the note, **Commit changes**. The next deploy publishes it.

## What to write

40–80 words. What the drive is actually like, where to park when it is busy,
which season you go, what to combine it with — what you would tell a friend.

Concrete beats lyrical. "20 minutter ad Vesterhavsvej, sidste stykke er grusvej,
og der er fyldt op på parkeringspladsen efter kl. 11 i juli" is worth more than
"en skøn oplevelse i smukke omgivelser".

This is the only thing on the site that no other page in the world can
reproduce. Everything else here is assembled from other people's pages, which is
exactly why those pages get cited instead of this one. Leave a place out if you
have nothing real to say about it — an empty block beats filler.

## Evergreen first

Worth writing for the places still worth reading next year: the six area pages,
and the lasting experiences — Lodbjerg Fyr, Thy Whisky, Nationalparkcenter,
Stenbjerg, Vestkyststien, Agger Tange, the walking routes, the restaurants.
Skip dated events; the note is stale before anyone reads it.
